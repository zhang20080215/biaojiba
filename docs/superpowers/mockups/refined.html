按真实尺寸 1080×1440 设计，这里缩到一半显示（点开看细节可以放大浏览器）。三张各用一种版式：榜单 = 杂志封面，月度 = 日程清单，单部 = 电影票根。精致度靠这几件事：72px 统一页边距、严格对齐的栅格、一套字号阶梯（96 / 64 / 34 / 28 / 22）、数字单独用 Inter、封面统一圆角加极淡描边和投影、大面积留白。

榜单 · 杂志封面。中间那块是 250 个点：黑 = 看过，橙 = 想看，灰 = 没看，一眼就是「我的 TOP250」。
每日电影 · 日程清单。照「赶场愉快」的排片单，按日期分组，白卡片浮在浅灰底上。
单部 · 电影票根。底色是这张封面的淡色模糊，每部片都不一样；票面信息全部来自记录（日期、星级、短评、平台评分）。
