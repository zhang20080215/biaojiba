# 分类与标记时间轴

## 页面变化

- 底部导航为：首页 / 分类 / 记录 / 我的。
- 分类页顶部为「榜单 / 每日标记」，榜单保留搜索、筛选、排序，每日标不论记独立展示四个入口。
- 原记录页的常用、最近使用、标记进度合并到「我的主题」，默认显示三项，可展开。
- 记录页改为个人时间轴：按操作时间倒序、分日期展示，支持封面、状态、来源入口和分页；大批量记录默认展示九项，可展开全部。

## 记录口径

- 成功保存之后才生成动态；失败、重复点击和跨榜自动同步不额外生成动态。
- 同一次榜单页面访问内，相邻操作间隔不超过两分钟合并成一条；离开后重新进入、超过两分钟或切换榜单开始新记录。
- 每次批量提交独立一条；部分失败时只记录成功的条目。每日运动一次保存多组只生成一条。
- 支持电影、图书、旅行榜单及每日电影、读书、运动、喝水。取消榜单标记也记录其动作，保留此前历史。
- 历史 Marks / BookMarks 只保存当前状态，无法恢复每次操作及已删除记录。因此不伪造历史流水；新时间轴从本版本开始积累，历史进度仍在「我的」。
- 本机持久队列按用户隔离；上传失败保留，后续启动或访问时间轴时重试。稳定记录 ID 与版本号保证重试不重复，旧版本不会覆盖新内容。

4. 发布小程序前，在开发环境验证上述云函数与集合权限。代码实现和本地测试已完成，本次未部署云端、未发布小程序。
