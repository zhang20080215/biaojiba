# 发版清单（2026-10-26，首页导航改版）

本版改动较大：底部四个 tab、首页 / 分类 / 我的重做、记录页预览、统一线条图标、每日统计重写、标记时间轴、期待上线计数、首页新广告位、Bangumi 新榜单。
**顺序原则：先云端、再数据、后前端。** 新前端依赖的云函数没部署时，页面能打开但人数、时间轴、期待计数都不工作。

## 一、云数据库（先做）

| 集合 | 用途 | 权限 | 备注 |
|---|---|---|---|
| `MarkTimeline` | 标记时间轴 | 客户端读写都禁止 | 复合索引：`openid` 升序 + `at` 降序 + `id` 降序 |
| `WishLikes` | 期待上线计数 | 客户端读写都禁止 | 函数首次写入会自动建；环境不允许自动建就手建 |
| `theme_hub_cache` | 首页人数快照 | 仅云函数写 | 已有 `public-v1` 文档**不要删**，旧文档没 `day` 字段，部署后第一个访客会触发一次完整统计 |

另外确认 `Marks` / `BookMarks` 上有 `openid` 索引（人数按 openid 区间分段去重依赖它）。

## 二、云函数（右键 → 上传并部署，云端安装依赖）

| 函数 | 类型 | 部署后核对 |
|---|---|---|
| `getThemeHub` | 新增 | **控制台核对线上超时 = 60 秒**（config.json 不一定生效）。测试 `{"action":"stats"}`，看 `success`、各行 `valid`/`users` |
| `markTimeline` | 新增 | 超时 20 秒 |

## 三、数据

1. **Bangumi 动画 Top 250（`bangumi250`）随包上线**，卡片写在本地目录里，发版前必须已灌库，否则首页 / 分类会出现一个空榜单。核对：`getThemeMovies` 传 `{"theme":"bangumi250","audit":true,"summaryOnly":true}`，`total` 应为 250，`missingCover` 接近 0。流程见 `tools/bangumi-seed/README.md`。
2. 其余新榜单（阿加莎、东野圭吾、豆瓣喜剧 / 科幻 / 悬疑、韩剧 / 日剧）走 `theme_registry` 动态注册，**和这次发版无关**，各自灌库核验后再导入注册文档即可，不必赶在这版。阿加莎的注册文档目前是 `enabled: false`。
3. 根目录 `database_export-*.json` 含用户 openid/昵称，已加入上传排除和 `.gitignore`；用完建议删除。

## 四、后台配置

1. **埋点事件注册**（小程序后台 → 数据分析 → 上报管理）。未注册的事件会静默丢失：
   - `hub_exposure`、`hub_click`：`page` / `theme` / `module` / `version` 均为字符串
   - `hub_favorite`：`theme` 字符串、`on` 整型、`version` 字符串
   - `records_wish_like`：`count` 整型（每人每天只报一次）
2. **广告**：新位 `home_top_native` 暂时复用 `category_native` 的广告单元，云端 `app_config` 不用改；要单独看数据就在流量主新建原生模板单元，把 id 换进 `utils/adConfig.js`。关停：云端 `placements.home_top_native.enabled = false`，无需发版。
3. **「记录」tab 云端开关**（10-27 补：首次提审因「记录功能点击无响应」被驳回）：底部 tab 已改为自定义组件 `custom-tab-bar/`，「记录」是否露出读云端 `app_config`（`key == 'ad_config'` 那条）的 `showRecordsTab`。
   - 提审前：确认该字段**不存在或为 `false`**，提审包只有 首页 / 分类 / 我的。
   - 过审发布后：在那条记录里加字段 `showRecordsTab`，类型**布尔值** `true`（字符串 `"true"` 不生效），用户下次进入即出现。
   - **不要跑 `initAdConfig`**：它会用代码里的旧值覆盖整条广告配置。
   - 页面内容仍由 `utils/hubFlags.js` 的 `recordsOpen: false` 决定（本地常量，打开时间轴需要再发一版）；只开 tab 时用户看到的是「打磨中」蒙版页。
